**修复优先级**: 🔴 高  
**影响**: 前端无法获取当前用户信息

### 2. 随机任务 API 返回空数据
**现象**: `GET /api/tasks/random` 返回 `{"success":false}`  
**原因**: 数据库无预设随机任务数据

### 3. 商店商品 API 返回空数据

**原因**: 数据库无商店商品数据  
**修复优先级**: 🟡 中  
**影响**: 奖励商店无法显示商品

### 4. 小屋 API 权限问题
**现象**: `GET /api/cottage/my` 返回 `ForbiddenError`
