**现象**: 返回 "Something went wrong"

**影响**: 前端无法获取当前用户信息  
**修复**: 已添加路由，需重启服务

#### 2. GET /api/users/preferences (HTTP 500)
**现象**: 内部服务器错误  
**原因**: 待排查（可能是数据解析问题）  
**影响**: 偏好设置功能不可用

### 🟡 中优先级 - 数据初始化问题

#### 3. GET /api/relationships (HTTP 404)
**现象**: 路由不存在  
**原因**: 路由未正确注册  
**影响**: 关系管理功能不可用

#### 4. GET /api/tasks (HTTP 404)
**现象**: 路由不存在  
**原因**: 路由未正确注册  
**影响**: 任务列表无法获取

#### 5. GET /api/tasks/random (HTTP 500)
**现象**: 内部服务器错误  
**原因**: 数据库无随机任务数据  
**影响**: 随机挑战功能不可用  
**解决**: 运行 seed 脚本初始化数据

#### 6. GET /api/admin/users (HTTP 404)
**现象**: 路由不存在  
**原因**: 路由未注册  
**影响**: 管理后台用户统计缺失

### 🟢 低优先级 - 权限/数据问题

#### 7. GET /api/rewards/my (HTTP 403)
**现象**: "Only growers have reward accounts"  
**原因**: admin 账号没有奖励账户  
**影响**: 仅管理员账号受影响  
**解决**: 正常现象，成长者账号可用

#### 8. GET /api/cottage/my (HTTP 403)
**现象**: "Only growers have cottages"  
**原因**: admin 账号没有小屋  
**影响**: 仅管理员账号受影响  
**解决**: 正常现象，成长者账号可用

#### 9. GET /api/certificates/1 (HTTP 404)
**现象**: "关系不存在"  
**原因**: ID=1 的关系不存在  
**影响**: 测试数据问题  
**解决**: 使用存在的关系 ID
