## 📋 端口占用问题解决记录 (2026-03-08 23:30-16:33 UTC)

**问题**：5173 端口被 PM2 管理的 python3 http.server 进程占用

**根本原因**：PM2 进程管理器自动重启 python http.server 进程占用 5173 端口

**解决方案**：
1. 使用 `pm2 list` 查找占用端口的 PM2 进程
2. 使用 `pm2 stop mvp-server && pm2 delete mvp-server` 停止并删除 PM2 进程
3. 清理 Vite 缓存：`rm -rf client/node_modules/.vite`
4. 重新启动服务

**验证命令**：
```bash
netstat -tlnp | grep 5173  # 检查端口占用
pm2 list                   # 查看 PM2 进程
pm2 delete mvp-server      # 删除 PM2 进程
```

**经验教训**：
- 启动服务前先检查端口占用
- 使用 PM2 管理的服务需要正确停止
- 清理缓存可避免 Vite 端口冲突

## 🐛 Bug 修复记录 #2 (2026-03-08 17:32 UTC)

**问题**：TrophyOutlined 导入错误
```
Uncaught SyntaxError: The requested module 
'/node_modules/.vite/deps/antd.js' 
does not provide an export named 'TrophyOutlined'
```

**原因**：图标从错误的包导入
- ❌ 错误：`import { TrophyOutlined } from 'antd'`
- ✅ 正确：`import { TrophyOutlined } from '@ant-design/icons'`

**修复文件**：
- `pages/cottage/Ranking.tsx` - 修正导入路径

**解决方案**：
1. 修改导入语句，从 `@ant-design/icons` 导入
2. 清理 Vite 缓存
3. 重启服务

**经验教训**：
- antd 组件从 `antd` 导入
- antd 图标从 `@ant-design/icons` 导入
- 不要混用两个包的导出
