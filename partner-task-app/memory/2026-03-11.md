## 技术要点

### 1. 角色权限逻辑
管理员账号可访问所有角色，普通用户只能访问自己的角色。

### 2. Token 刷新
切换角色时生成新 Token，包含新的 currentRole。

### 3. Chakra UI v2
使用 v2 版本避免与 React 18 的版本冲突。

### 4. API 导入
项目使用 default export，所有导入必须是 `import api from`。
