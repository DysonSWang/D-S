## ⚠️ 发现的问题

### Bug #001 - API 限流过于严格
- **标题**: 登录 API 限流导致测试无法继续
- **严重程度**: Medium
- **模块**: 认证 API
- **复现步骤**:
  1. 快速多次调用登录 API（5 次以上）
  2. 返回 "Too many login attempts" 错误
  3. 限流持续时间较长（超过 30 秒）
- **预期结果**: 限流时间应该较短，或者有白名单机制
- **实际结果**: 限流影响测试执行
- **建议**: 
  - 开发环境放宽限流
  - 或添加测试账号白名单
  - 或限流时间缩短至 10 秒

### Bug #002 - 创建任务 API 参数不明确
- **标题**: 创建任务需要 relationshipId 但文档未说明
- **严重程度**: Low
- **模块**: 任务 API
- **复现步骤**:
  1. 调用 POST /api/tasks
  2. 不提供 relationshipId 参数
  3. 返回内部错误
- **预期结果**: 应返回明确的参数错误提示
- **实际结果**: 返回 "INTERNAL_ERROR"
- **建议**: 添加参数验证，返回清晰的错误信息
