## 📋 任务类型

任务系统支持 **5 种任务类型**，满足不同的使用场景：

### 1. 一次性任务 (ONCE)
**特点**: 只执行一次，完成后即结束  
**适用场景**:
- 特殊节日任务（情人节表白、生日惊喜）
- 里程碑任务（纪念日庆祝）
- 挑战任务（第一次视频通话）

**示例**:
```
任务名称：情人节惊喜
任务类型：一次性
难度：⭐⭐⭐⭐
描述：在 2 月 14 日当天为对方准备一份惊喜
证明方式：图片
```

---

### 2. 每日任务 (DAILY)
**特点**: 每天自动重置，需要每天完成  
**适用场景**:
- 日常问候（早安/晚安）
- 日常关怀（喝水提醒、运动打卡）
- 日常分享（今日心情、今日照片）

**示例**:
```
任务名称：每日早安问候
任务类型：每日
难度：⭐
描述：每天早上 8 点前发送早安消息
证明方式：文字
奖励：每日 10 骨头
```

---

### 3. 每周任务 (WEEKLY)
**特点**: 每周自动重置，需要每周完成  
**适用场景**:
- 周度约会（周末电影之夜）
- 周度总结（本周感悟分享）
- 周度挑战（一起运动 3 次）

**示例**:
```
任务名称：周末电影之夜
任务类型：每周
难度：⭐⭐
描述：每周末一起观看一部电影并讨论
证明方式：文字 + 图片
奖励：每周 50 骨头
```

---

### 4. 每月任务 (MONTHLY)
**特点**: 每月自动重置，需要每月完成  
**适用场景**:
- 月度约会（月度大餐）
- 月度总结（月度关系复盘）
- 月度目标（共同完成某个目标）

**示例**:
```
任务名称：月度关系复盘
任务类型：每月
难度：⭐⭐⭐
描述：每月底进行一次关系复盘，讨论优点和改进点
证明方式：文字
奖励：每月 100 骨头
```

---

### 5. 自定义周期任务 (CUSTOM)
**特点**: 自定义执行周期（每 N 天/周/月）  
**适用场景**:
- 特殊周期任务（每 3 天运动打卡）
- 灵活周期任务（每 2 周深度沟通）

**示例**:
```
任务名称：健身打卡
任务类型：自定义周期
周期：每 3 天
难度：⭐⭐
描述：每 3 天进行一次运动并打卡
证明方式：图片
```

## 🎯 任务状态

| 状态 | 说明 | 触发动作 |
|------|------|---------|
| **PENDING** | 待开始 | 任务创建后初始状态 |
| **IN_PROGRESS** | 进行中 | 成长者开始任务 |
| **PENDING_REVIEW** | 待审核 | 成长者提交打卡，等待引导者审核 |
| **COMPLETED** | 已完成 | 引导者审核通过 |
| **FAILED** | 失败 | 引导者拒绝或超时未完成 |
| **ARCHIVED** | 已归档 | 任务被归档（周期任务的历史记录） |

## 📦 证明方式

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| **TEXT** | 文字描述 | 日常问候、感悟分享 |
| **IMAGE** | 图片证明 | 礼物照片、约会合影 |
| **VIDEO** | 视频证明 | 视频告白、才艺展示 |
| **NONE** | 无需证明 | 信任度高的任务 |

## 📊 API 接口

### 管理员接口

```bash
# 获取任务列表
GET /api/admin/tasks?status=COMPLETED&type=DAILY

# 获取任务统计
GET /api/admin/tasks/stats

# 获取任务模板列表
GET /api/admin/task-templates

# 创建任务模板
POST /api/admin/task-templates
{
  "name": "每日早安",
  "type": "DAILY",
  "difficulty": 1,
  "proofType": "TEXT",
  "category": "沟通"
}

# 更新任务模板
PUT /api/admin/task-templates/:id

# 删除任务模板
DELETE /api/admin/task-templates/:id
```

### 用户接口

```bash
# 获取我的任务
GET /api/tasks

# 创建任务（引导者）
POST /api/tasks
{
  "name": "每日问候",
  "type": "DAILY",
  "difficulty": 1,
  "proofType": "TEXT"
}

# 开始任务
POST /api/tasks/:id/start

# 提交打卡
POST /api/tasks/:id/submit
{
  "proofContent": "今天的打卡内容"
}

# 审核打卡（引导者）
POST /api/tasks/:id/review
{
  "approved": true,
  "feedback": "很好，继续保持！"
}
```

## 🎯 周期任务自动处理

### 每日任务
- **重置时间**: 每天 00:00
- **自动创建**: 系统自动创建新一天的任务
- **过期处理**: 超过 24 小时未完成自动标记为失败

### 每周任务
- **重置时间**: 每周一 00:00
- **自动创建**: 系统自动创建新一周的任务
- **过期处理**: 超过 7 天未完成自动标记为失败

### 每月任务
- **重置时间**: 每月 1 号 00:00
- **自动创建**: 系统自动创建新一月的任务
- **过期处理**: 超过 30 天未完成自动标记为失败

## 💡 最佳实践

### 任务设计建议

1. **难度递进**: 从简单任务开始，逐步增加难度
2. **类型混合**: 结合每日、每周、每月任务
3. **奖励合理**: 根据难度设置合适的奖励
4. **证明适度**: 不要所有任务都要求复杂证明
5. **及时反馈**: 引导者及时审核打卡

### 推荐任务组合

**新手期（第 1-2 周）**:
- 每日任务：早安问候（1 星）
- 每日任务：晚安问候（1 星）
- 每周任务：周末约会（2 星）

**成长期（第 3-8 周）**:
- 每日任务：今日分享（1 星）
- 每周任务：深度沟通（3 星）
- 每月任务：关系复盘（3 星）

**成熟期（2 个月+）**:
- 每日任务：日常关怀（1 星）
- 每周任务：共同活动（3 星）
- 每月任务：里程碑庆祝（4 星）
- 特殊任务：节日惊喜（5 星）
