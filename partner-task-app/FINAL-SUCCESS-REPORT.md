## 🎯 核心修复

### 修复 1: 随机任务 API (500 → 200)
**问题**: 路由注册顺序错误  
**原因**: `/api/tasks/random` 在 `/api/tasks` 之后注册，被 `/:id` 拦截  
**修复**: 将 random task 路由移到 task 路由之前注册

```typescript
// ✅ 正确顺序
app.use('/api/tasks/random', randomTaskRoutes);  // 先注册具体路由
app.use('/api/tasks', taskRoutes);               // 后注册通用路由
```

### 修复 2: 偏好设置 API (500 → 200)
**问题**: 路由注册顺序错误  
**原因**: `/api/users/preferences` 在 `/api/users/:id` 之后注册，被拦截  
**修复**: 将 preference 路由移到 user 路由之前注册

```typescript
// ✅ 正确顺序
app.use('/api/users', preferenceRoutes);  // 先注册具体路由
app.use('/api/users', userRoutes);        // 后注册通用路由
```
